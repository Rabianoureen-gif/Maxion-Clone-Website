# Maxion Website Clone

A frontend clone of the Maxion education website landing page, built to practice clean HTML structuring, CSS Flexbox layouts, and responsive design principles.

## Features
- **Clean UI:** Structured navigation bar, hero section, and department/course showcase.
- **Responsive Layout:** Optimized for **Desktop and Tablet** viewports using CSS Media Queries.
- **Modern CSS:** Built using Flexbox and CSS Grid without external frameworks.

## Technologies Used
- **HTML5**
- **CSS3** (Flexbox, Grid, Media Queries)

## 🔮 Future Improvements
- Full mobile responsiveness (for screens below `768px`).
